rss · Lenny&\#x27;s Newsletter · Oct 19, 12:04

**「Claude Code + Whisper + FFmpeg pipeline」** Brooke Lacey runs Claude Code in the terminal as an orchestrator over two open-source command-line tools: OpenAI Whisper generates word-level timestamps from the raw audio track, and FFmpeg executes the actual cuts and zoom adjustments without opening traditional editing software. Claude Code builds a text-based cut list from those timestamps, which is how a raw phone video becomes a captioned, jump-cut TikTok in roughly 15 seconds.

**「Takeaway」** Test Claude Code as a first-pass editor on raw phone footage to automate captioning and jump cuts, then review the output before publishing to see whether it holds up against your manual edit.

### [健身业用WorkBuddy落地四个AI Agent场景：唤醒、体测、获客、档案](https://www.woshipm.com/ai/6481645.html) ⭐️ 6.0/10

作者马佳彬以健身房续约率仅约三成为痛点，拆解了用AI办公Agent WorkBuddy在健身行业落地的四个实操场景。第一是沉睡会员唤醒：上传含姓名、卡种、办卡日期、最近到店时间、剩余私教课时的会员名单，让AI按“超两个月未到店、一个月内到期未续、私教课剩三节以内”分三组，每组生成十条两行以内的微信话术，并预留个性化补充空位。第二是体测报告解读：把体测数据翻译成大白话并输出八周训练方向初稿，由教练二次审核。第三是同城内容获客：参照漳州一家健身房“干货教学四成、避坑科普三成、真实效果两成、门店日常一成”的内容配比批量生成口播脚本，采用前5秒戳痛点、中间15秒教学、结尾引导团购体验券的结构。第四是用提示词直接生成会员跟进网页，把到期提醒、体测曲线和跟进记录集中到手机端今日待跟进列表。作者强调优惠力度、续费价格等数字AI会编造，必须人工审核，且健身属广告法重点监管行业，不能写效果承诺。

rss · 人人都是产品经理 · Oct 21, 01:45

**「AI技术要点」** 核心是用WorkBuddy这类通用AI办公Agent执行提示词任务：上传表格做会员分层与话术生成、把体测数据转译成通俗讲解稿、按固定内容配比批量产出短视频脚本，以及通过自然语言提示直接生成含前后端的会员管理网页应用。作者还提到可在技能市场安装健身训练、douyin-ops（含违禁词检测）、xhs-copywriter等Skill，但建议每类只装一个以免占用上下文、浪费token。

**「增长影响」** 文中唯一的量化背景是健身行业中大型俱乐部续约率约三成，即十个会员里七个后续不再到店；作者未提供任何A/B测试或转化、留存、获客成本数据来验证四个场景的实际效果，因此这些做法目前属于待验证的早期实践分享。

**「可复用要点」** 把会员名单交给AI按“沉睡、临期、课将尽”三类分层并生成带个性化空位的话术模板，比统一群发更能避免模板感，但涉及价格、赠品和效果承诺的内容必须由店内人员按实际政策人工定稿。
