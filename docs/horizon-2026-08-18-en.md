### [DeepSeek Harness: Plugin Architecture and Growth Opportunities](https://www.woshipm.com/ai/6449308.html) ⭐️ 7.0/10

DeepSeek open-sourced dsh \(DeepSeek Harness\), an AI agent framework built on a &\#x27;everything is a plugin&\#x27; philosophy, which quickly gained 115,000 GitHub stars within three days. The framework allows agents to self-evolve by creating and mounting new plugins at runtime, and it is built on the Cordis microkernel with reversible effects and dependency injection, validated by over 4,000 plugins in the Koishi ecosystem. However, a community plugin caused a 400GB data loss due to a command escaping error, highlighting significant safety risks. The article argues that agent reliability is now determined by harness quality rather than model quality, citing LangChain&\#x27;s Terminal Bench 2.0 score improvement from 52.8% to 66.5% with harness optimization alone, and OpenAI&\#x27;s team delivering ~1 million lines of code with agents. This shift moves the competitive moat from model training to engineering and industry know-how, creating opportunities for plugin-based assets that encapsulate domain expertise. The article also notes DeepSeek&\#x27;s &\#x27;razor-blade&\#x27; strategy of open-sourcing the runtime while raising API prices, and the emergence of a data flywheel. For growth practitioners, the key takeaway is that plugin ecosystems represent a new asset class for packaging industry knowledge, but safety mechanisms must be carefully managed to avoid catastrophic failures.

rss · 人人都是产品经理 · Aug 18, 01:01

**「AI Technique」** DeepSeek Harness \(dsh\) is an open-source agent framework built on a microkernel called Cordis, which implements a plugin-based architecture where every agent capability—including the core agent loop—is a plugin. It uses reversible effects and dependency injection to allow hot-swapping and automatic rollback of plugins at runtime. The framework enables agent self-evolution through self-referential tools \(cordis\_inspect, cordis\_define, cordis\_run\) that let the agent inspect, create, and mount new plugins on the fly. This design is grounded in a programming paradigm called &\#x27;spatiotemporal composability,&\#x27; as described in DeepSeek&\#x27;s paper, allowing plugins to be composed and removed without residue and state to roll back to any point in time.

**「Growth Impact」** The DeepSeek Harness \(dsh\) framework has demonstrated significant community-driven growth, with GitHub stars surging from 55,000 to 115,000 within three days of its open-source release, and the plugin ecosystem expanding from 288 to over 4,000 plugins in a single day. This rapid adoption signals strong developer interest and validates the &\#x27;everything is a plugin&\#x27; architecture as a viable growth lever. For growth practitioners, the key takeaway is that an open-source, plugin-first strategy can accelerate ecosystem growth and create a new asset class of reusable, industry-specific plugins, shifting competitive advantage from model capability to harness engineering and domain know-how. However, the reported 400G data loss incident underscores the critical need for robust permission management and safety guardrails when deploying such powerful agent frameworks.

**「Takeaway」** Growth practitioners should explore packaging industry-specific workflows as reusable plugins on agent frameworks like dsh, as this represents a new asset class for scaling AI solutions, but must implement strict permission controls and review mechanisms to prevent data loss incidents.
