### [AI 支付窗口期：代理商务全景与玩家卡位](https://www.woshipm.com/ai/6461637.html) ⭐️ 8.0/10

本文梳理了 AI 支付（即 AI 代理支付）在代理商务（Agentic Commerce）中的发展阶段与全球玩家布局。2025 年被视为 AI 支付元年，Google、Stripe、OpenAI、Visa、Mastercard、支付宝等密集发布协议，如 AP2、ACP、TAP 等；2026 年协议加速落地，支付宝 AI 支付累计完成 3 亿笔，用户数突破 1 亿，蚂蚁国际面向全球推出 AMP，Mastercard 在亚太完成实时智能体交易。文章指出，AI 支付本质是面向“机器客户”重建信任体系，支付网络正为 Agent 重新设计信任层，各玩家在协议层、卡组织、钱包等环节卡位，但尚无一家能定义完整规则。对增长从业者而言，理解这一趋势有助于把握代理商务的信任基础设施变化，提前布局相关能力。

rss · 人人都是产品经理 · 9月9日 00:58

**「AI 技术」** AI 支付的核心技术在于通过专用协议（如 AP2、ACP、TAP）实现智能体（Agent）的身份验证、授权与支付执行，使机器能够作为独立交易主体发起和完成支付，同时利用 Token 化技术（如 Agentic Token）替代传统静态卡号以增强安全性。

**「行动建议」** 增长从业者应关注 AI 支付协议与平台开放能力，尽早接入如支付宝 AMP、Stripe ACP 等生态，以在代理商务爆发期占据先发优势。

### [OpenAI 靠广告年入 10 亿美元，中国大模型靠 API 与算力：盈利模式对比](https://www.woshipm.com/ai/6462101.html) ⭐️ 7.0/10

OpenAI 已将其广告业务发展为年化收入达 10 亿美元的引擎，其基础是 92% 的 ChatGPT 用户为免费用户，广告于 2026 年 2 月上线，8 月 31 日官方宣布年化收入达到 10 亿美元，并扩展至 40 多个国家。相比之下，中国大模型公司主要采用按 Token 调用量收费的 API 模式，例如智谱 2026 年上半年 API 业务收入同比增长 2735.7%，Kimi 的 ARR 在三个月内从 1 亿美元增至 3 亿美元，DeepSeek 前七个月收入约为 2025 年全年的 10 倍。此外，阿里云和百度等云厂商通过出售 GPU 算力获得可观收入，而字节跳动旗下火山引擎的 MaaS 日均 Token 调用量超 180 万亿。尽管收入增长迅速，但中国大模型公司普遍亏损，如智谱上半年净亏损 19.64 亿元，阿里千问板块单季 EBITA 亏损 138.61 亿元，表明行业仍处于用收入增速换取亏损规模的阶段。这一对比凸显了两种截然不同的变现路径：OpenAI 将免费流量转化为广告收入，而中国公司则押注于将模型作为基础设施按量收费，后者虽然增长较慢但毛利结构更健康，且客户粘性更强。对于增长从业者而言，理解这两种模式的底层逻辑有助于根据自身用户结构和生态选择更合适的商业化策略。

rss · 人人都是产品经理 · 9月9日 02:56

**「AI 技术应用」** 本文涉及的 AI 技术主要是大语言模型（LLM）的规模化部署与商业化，包括 OpenAI 将 ChatGPT 作为流量平台，通过广告系统（如 Ads Manager）实现变现，以及中国公司提供的模型即服务（MaaS），通过 API 按 Token 调用量收费。此外，还涉及云厂商提供的 GPU 算力服务，支撑模型训练与推理。

**「增长影响」** OpenAI 的广告业务在 6 个月内实现年化收入从 0 到 10 亿美元的增长，主要得益于其庞大的免费用户基础（92% 的消费者用户不付费），通过广告将免费流量转化为收入。中国大模型公司则通过 API 调用量实现高速增长，如智谱 API 业务收入同比增长 2735.7%，Kimi ARR 三个月翻三倍，但普遍面临亏损，表明增长与盈利尚未平衡。

**「行动建议」** 增长从业者应根据自身用户结构和生态选择变现路径：若拥有海量免费 C 端用户，可探索广告模式；若面向 B 端，则应聚焦 API 或行业解决方案，以建立更可持续的现金流。
