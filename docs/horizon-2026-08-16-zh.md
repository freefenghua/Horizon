### [别分类，让 AI“幻觉”出标签：用嵌入匹配实现大规模内容打标](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) ⭐️ 7.0/10

Simon Willison 介绍了一种为未打标内容自动生成标签的实用技巧：与其让 LLM 在庞大的现有标签列表中挑选，不如先让模型“幻觉”出可能的新标签，再通过向量嵌入将这些虚构标签与现有标签库进行相似度匹配，从而找到最合适的真实标签。该方法解决了内容运营中大规模打标的痛点，尤其适用于标签数量庞大（如 Simon 博客的 1,856 个标签）而无法一次性输入给 LLM 的场景。文章提供了具体的提示词示例，展示了如何通过示例标签形状引导模型生成更合理的候选标签。虽然该技巧具有高度的可复制性和实操性，但作者并未提供具体的性能数据或完整案例研究，因此其实际效果仍需读者自行验证。对于需要处理海量内容分类的运营人员而言，这一方法提供了一种高效且低成本的替代方案。

rss · Simon Willison · 8月14日 21:54

**「AI 技术」** 该技巧利用 LLM 的生成能力，先让模型基于内容或查询生成全新的、未见过的标签（即“幻觉”），然后使用嵌入模型将这些虚构标签与现有标签库进行向量相似度匹配，从而将虚构标签映射到最接近的真实标签。这种方法避免了将整个标签库输入给 LLM 的上下文限制，同时利用了嵌入的语义理解能力。

**「增长影响」** 该技巧主要提升内容运营效率，通过自动化打标流程，减少人工分类的时间和成本，从而间接支持内容发现和 SEO 优化。虽然文中未提供具体的量化指标（如转化率提升或成本降低），但该方法可显著降低大规模内容打标的门槛，尤其适用于拥有大量历史内容且标签体系复杂的平台。

**「行动建议」** 运营人员可以借鉴此方法：当标签体系过于庞大时，先让 LLM 生成候选标签，再通过嵌入匹配映射到现有标签，从而快速实现内容打标，无需人工逐一分类。

**「实践启示」** 增长从业者应将 Agent 视为一套可运营的系统，而非单一模型，通过明确岗位边界、权限表和人工接管机制，确保自动化提升不损害质量与责任边界。
