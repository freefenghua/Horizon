### [别分类，去幻觉：用向量嵌入给旧内容打标签](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) ⭐️ 7.0/10

Simon Willison 介绍了一种利用 LLM 幻觉和向量嵌入为未标记内容打标签的实用技术。该方法先让模型自由生成可能的新标签，而不受现有标签词汇限制，然后通过向量嵌入将这些虚构标签与现有标签库中的实际标签进行匹配，找到最接近的标签。这一技术解决了标签数量庞大（如 Simon 博客有 1,856 个标签）时难以直接让 LLM 分类的问题。虽然该案例没有提供具体的增长指标，但它为内容组织、SEO 和个性化推荐等增长相关任务提供了一种可复制的自动化工作流。

rss · Simon Willison · 8月14日 21:54

**「AI 技术」** 该技术结合了 LLM 的生成能力与向量嵌入的相似性搜索：LLM 被提示生成符合内容的新颖分类标签，然后使用向量嵌入将这些生成的标签与现有标签库中的标签进行语义匹配，从而将内容映射到最合适的现有标签。

**「增长影响」** 该技术通过自动化内容标签化，能够提升内容组织效率，进而改善站内搜索和推荐系统的准确性，可能带来更高的用户参与度和留存率。但该案例未提供具体的量化指标，因此其增长影响尚需进一步验证。

**「实践要点」** 增长从业者可以借鉴此方法，利用 LLM 生成候选标签，再通过向量嵌入匹配现有标签体系，从而高效地为大量未标记内容打标签，提升内容发现和个性化推荐的效率。

### [GLM-5.3 实测：长程调度 Agent Loop 能力解析与提示词设计指南](https://www.woshipm.com/share/6447609.html) ⭐️ 6.0/10

本文实测了智谱最新发布的 GLM-5.3 模型，重点展示了其在长程调度（Long-Horizon）和 Agent Loop 方面的能力。作者通过多个案例（如从 0 到 1 复刻《传奇》游戏、制作像素闯关游戏、模拟放置游戏、红蓝网络攻防等）验证了 GLM-5.3 能够自主将复杂任务拆解为多步执行，并在循环中自我修正和迭代，最终产出可交付的成果。官方数据显示，GLM-5.3 的编程能力较上一代提升约 50%，在 Terminal-Bench 3.0 上达到开源模型第一，自研 Code Bench 超过 Claude Opus 4.8，且 token 消耗更少。然而，该模型目前为纯文本单模态，缺乏视觉能力，需要依赖 GLM 4.6V 作为“眼睛”。文章还总结了设计长程调度提示词的五条建议，强调状态存储、循环轮次、停止条件、错误处理和记忆精简的重要性。对于增长从业者而言，GLM-5.3 展示了 AI 从“会写”到“会完成”的跨越，意味着 AI 可以更自主地处理复杂业务任务，减少人工干预，提升效率。

rss · 人人都是产品经理 · 8月15日 09:02

**「AI 技术解析」** GLM-5.3 是智谱 AI 发布的旗舰模型，基于与 GLM-5.2 相同的 743B 参数 MoE 基座模型，但通过极致的后训练 Scaling（数十倍的长程任务环境、更丰富的环境类型、超长的后训练时间）显著提升了长程调度（Long-Horizon）能力。其核心是 Agent Loop：模型自主执行「干活 → 看结果 → 再决定下一步」的循环，能跨多轮任务保持状态记忆，并在出错时自我修正。官方数据显示，其编程能力较上一代提升约 50%，Terminal-Bench 3.0 达到开源模型第一，自研 Code Bench 超过 Claude Opus 4.8。目前为纯文本单模态模型，视觉能力需依赖 GLM 4.6V 补充。

**「增长影响」** GLM-5.3 的长程调度能力使 AI 能够自主完成多步骤任务，如从零开发一个完整游戏，这显著降低了内容生产和产品开发的人力成本。虽然文章未提供具体的增长指标，但作者指出，这种能力让 AI 从“demo”走向“生产环境”，意味着企业可以用更少的资源实现更复杂的自动化流程，从而提升运营效率和响应速度。对于增长团队，这意味着可以快速生成原型、自动化内容创作或优化用户交互流程，但具体效果需结合业务场景验证。

**「行动建议」** 增长从业者可以借鉴文章中的提示词设计原则，在 AI 工具中明确要求模型分步执行、保存进度、设定停止条件、从错误中学习并精简记忆，从而让 AI 更可靠地完成长周期任务，提升自动化效率。
