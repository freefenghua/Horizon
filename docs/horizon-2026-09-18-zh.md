### [用 WorkBuddy 反推爆款视频：半小时复刻一条的 AI 流水线](https://www.woshipm.com/ai/6466020.html) ⭐️ 6.0/10

作者晓庄同学在人人都是产品经理发文，介绍把一套「反推 skill」交给 WorkBuddy，用五步流水线（丢视频→反推提示词→生视频→包装视频→成片）复刻爆款视频。实测中，把一条 13.6 秒的爆款 AI 短剧链接丢给 WorkBuddy，29 分 14 秒后拿到包含影片概况、剧情还原和「六件套」核心的反推报告；配置 Skill 阶段耗时 7 分 55 秒，产出 4 个脚本和 2 份参考文档。分析环节使用 ffprobe 测比例、时长、帧率，均匀抽帧逐帧看画面，并用 Whisper 把音频转成文字，最终按「十维度」整理出可直接投喂给模型的提示词。作者强调反推不是照搬原片，而是拆解手法后用新内容重做，并指出提示词会过期、拆解出的判断力才是可带走的资产。需要说明的是，文中未公布复刻视频的播放、点赞、转化等硬性效果数据，属于单次实测的经验分享。

rss · 人人都是产品经理 · 9月18日 00:52

**「AI 技术拆解」** 核心是把视频反推任务封装成一个可运行的 Skill 交给 WorkBuddy 执行：先用 ffprobe 读取视频参数并均匀抽帧，让模型逐帧理解画面，再用 Whisper 做音频转写，最后按主体、场景、动作、镜头运动、光线、风格、比例、时长、台词、氛围十个维度生成结构化提示词，并附带负面提示词和角色设定档案。生成的提示词可投喂给 seedance2.0 等视频模型，也可免费丢进豆包试生成。

**「增长影响」** 该案例的价值在于把原本依赖运营、编剧人工拆片和写脚本的环节，压缩为「一个人 + 一条流水线」，作者称人力成本和学习成本一起下降，实测从丢链接到拿到报告约 29 分钟。但文中没有给出复刻视频的播放量、点赞、转化或留存等可量化增长结果，效果仍属单次 anecdotal 验证，落地前建议自行小规模测试。

**「可复用要点」** 与其直接抄爆款内容，不如用 AI 把爆款的镜头语言、节奏和信息密度拆成结构化提示词，再用自己的素材重做，并把每次拆解沉淀为可复用的判断力而非一次性提示词。

### [腾讯开源 Agent 记忆平台：把团队经验变成可分配的记忆资产](https://www.woshipm.com/ai/6465993.html) ⭐️ 6.0/10

腾讯将 Agent 记忆能力做成了可部署的 TencentDB-Agent-Memory，把对话记忆、可复用技能、项目文档和代码关系统一组织为「记忆资产」，再通过 Team、Agent、权限和绑定关系分配给不同角色的 Agent 使用。它由 Memory Core、Memory Hub 和 Memory Proxy 三个服务协同工作，记忆采用 L0 到 L3 的分层结构，检索时结合 BM25 关键词检索、向量检索和 RRF 排序。作者在 Windows WSL 环境中通过克隆仓库、修改 .env 中的 memory 组与 proxy 组模型参数、运行 verify.sh 验证、执行 start-all.sh 一键启动、打开 localhost:8125 管理面板四步完成部署。该工具主要解决新会话反复解释项目背景、不同 Agent 重复阅读相同文档、已验证方案无法复用三类重复劳动，对需要管理 Agent 工作流与团队知识资产的团队有直接参考价值，但原文未提供任何增长指标数据。

### [用户场景定义方法论：从需求堆砌到价值锚定](https://www.woshipm.com/pd/6466198.html) ⭐️ 5.0/10
